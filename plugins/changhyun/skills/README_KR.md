# 스킬

이 디렉토리에는 `changhyun` 플러그인의 Claude Code 스킬이 포함되어 있습니다.

---

## economic-news

WebFetch를 사용해 최신 한국 경제 뉴스를 가져오고 요약·분석합니다.

### 지원 사이트

WebFetch를 통한 기사 목록 및 본문 접근이 검증된 사이트 목록입니다:

| 사이트 | 도메인 | 본문 품질 |
|--------|--------|----------|
| 한국경제 | hankyung.com | 핵심 내용 + 수치 구조화 |
| 서울경제 | sedaily.com | 소제목별 섹션 분해, 인용문 풍부 |
| 헤럴드경제 | biz.heraldcorp.com | 원문 충실도 최고, 단락 구조 그대로 |
| 이데일리 | edaily.co.kr | 상세 내용 + 수치 포함 |
| 뉴시스 | newsis.com | 핵심 내용 + 인용문 포함 |

### 제외된 사이트

| 사이트 | 제외 사유 |
|--------|---------|
| mk.co.kr | WebFetch 차단됨 |
| yna.co.kr | WebFetch 차단됨 |
| biz.chosun.com | WebFetch 차단됨 |
| fnnews.com | 404 오류 |
| news1.kr | 본문이 압축·요약되어 품질 부족 |

### 사용 시점

다음과 같은 요청 시 이 스킬을 사용합니다:
- 오늘의 경제 뉴스
- 특정 주제 뉴스 (예: 반도체, 환율, 부동산)
- 특정 언론사 뉴스
- 경제 동향 브리핑
